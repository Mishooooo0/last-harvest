# Last Harvest — opening artwork

Created with the built-in imagegen tool. The final images use the live game's simple top-down pixel-art style, following the user's correction that the first cinematic paintings looked too realistic. The discarded realistic drafts are not shipped with the game.

The game screenshot was supplied as a style reference, not as an image to repaint. These are generated story illustrations, not exact screenshots of the starting farm; survival rules are in HTML captions.

## Final prompts

### 1 — 01-outbreak.png

Use case: illustration-story. Create ONE new opening-story still for Last Harvest. The attached screenshot is a STYLE REFERENCE ONLY: match its actual simple 2D game graphics closely. Do not repaint the screenshot. Build a new rural town outbreak scene from the same type of small game sprites and tiles. STRICT STYLE: a screenshot from a simple low-budget 16-bit top-down farming game; chunky square pixels, flat colors, small rectangular sprites with heads about 6x6 pixels, tiny dot eyes, minimal face detail, squat geometric wood buildings, restrained 24-32 color muted olive/khaki/brown palette. Image should look like native 320x180 pixel art enlarged cleanly 4x with nearest-neighbor, not a detailed illustration. A fixed elevated top-down/isometric-ish game camera, just like the reference farm. Scene: a small country town with 3 simple buildings, one abandoned red produce truck, two square-pixel smoke plumes, a few green zombie sprites down the road. Four tiny survivors stand by the truck, heading toward a road out: farmer in straw hat/red shirt, blue-shirt woman, ochre-shirt man, green-shirt woman. A simple seed sack beside farmer. The outbreak has reached town; readable non-graphic storytelling. Landscape 16:9, no UI, no minimap, no text, no lettering, no decorative border. No photorealism, no painterly or realistic concept art, no cinematic depth of field, no anatomically detailed people, no intricate texture, no smooth gradients. This needs to feel like the same game, not a different AAA game.
